## 🎯 About SteadySense

SteadySense is an intelligent Android application designed for elderly users and their caretakers:

- ✅ **Automated Fall Detection** - Real-time sensor-based fall detection
- ✅ **Emergency SOS Alerts** - One-tap alerts with location sharing
- ✅ **Live Location Tracking** - Interactive map for real-time monitoring
- ✅ **Dual Dashboard** - Separate interfaces for elders and caretakers
- ✅ **AI Voice Assistant** - Multi-language support (English & Urdu)
- ✅ **Health Monitoring** - Activity tracking and step counting
- ✅ **Secure Authentication** - Firebase-powered user authentication

## 🚀 Quick Start

### Prerequisites
- Android 8.0 or higher
- ~50MB free storage space
- Internet connection
- Device with accelerometer & gyroscope

### Installation Steps

1. **Download APK**
   ```
   Link: https://github.com/SachalVerse/SteadySense/raw/main/apk/SteadySense.apk
   Size: 14.5 MB
   ```

2. **Enable Unknown Sources**
   - Settings → Security → Unknown Sources → Enable

3. **Install Application**
   - Open SteadySense.apk → Tap Install

4. **Grant Permissions**
   - Accept all permissions when prompted

5. **Register & Start Using**
   - Create account as Elder or Caretaker
   - Complete profile setup
   - Start monitoring

## 🐛 Common Issues

### Installation
- **"Unknown Sources" error**: Enable in Settings
- **Installation fails**: Check 50MB free storage
- **APK corrupted**: Re-download from link

### Runtime
- **Location not updating**: Enable background location
- **No notifications**: Check battery optimization
- **Fall detection issues**: Calibrate sensors
