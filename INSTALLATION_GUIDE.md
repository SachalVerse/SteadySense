# Installation Guide - SteadySense v1.0.0

Complete step-by-step guide to install and set up SteadySense on your Android device.

---

## 📱 System Requirements

Before installing, ensure your device meets these requirements:

- **Android Version**: 8.0 or higher
- **Storage Space**: Minimum 50MB free space
- **RAM**: At least 2GB (4GB recommended)
- **Sensors**: Accelerometer and Gyroscope
- **Internet**: WiFi or mobile data connection
- **Device**: Any modern Android phone or tablet

## 🔓 Enable Unknown Sources

**Important**: Before installing, you must allow installation from unknown sources.

### For Android 8.0-11:
1. Open `Settings`
2. Navigate to `Security` or `Applications`
3. Look for `Unknown Sources` or `Install Unknown Apps`
4. Enable the toggle switch
5. Confirm the action

### For Android 12+:
1. Open `Settings`
2. Go to `Apps` → `Special App Access`
3. Select `Install Unknown Apps`
4. Choose your file manager/browser
5. Enable the permission

## 🔧 Installation Steps

### Step 1: Locate the APK File
- Open `File Manager` or `My Files` app
- Navigate to `Downloads` folder
- Look for `SteadySense.apk`

### Step 2: Open the APK File
- Long-press on `SteadySense.apk`
- Select `Open` or `Install`
- System will show installation prompt

### Step 3: Review App Information
- Read app permissions and details
- Verify official source
- Check file size: ~14.5 MB

### Step 4: Tap Install
- Button shows `Install`
- Tap to begin installation
- Wait for progress to complete (30-60 seconds)

### Step 5: Installation Complete
- You'll see `Installed` or `Open` button
- Tap `Open` to launch immediately
- Or close and launch later from app drawer

### Step 6: Grant Permissions
When app launches for first time:
- Accept permissions prompt
- Select `Allow All` or grant individually
- Dismiss any setup wizards

**Location Settings:**
```
Settings → Location
├─ Enable Location Services
├─ High Accuracy mode
└─ Allow background location
```

**Battery Optimization:**
```
Settings → Battery → Battery Optimization
├─ Find SteadySense
└─ Select "Don't Optimize"
```

**Notification Settings:**
```
Settings → Apps → SteadySense → Notifications
├─ Enable All Notifications
└─ Set Priority: High
```

## 🆘 Troubleshooting Installation

### Issue: "App Not Installed" Error
**Solution:**
- Check 50MB free storage
- Uninstall old version
- Download APK again
- Restart device

### Issue: Installation Hangs/Freezes
**Solution:**
- Close other apps
- Restart device
- Ensure stable internet
- Try downloading again

### Issue: "Unknown Sources" Not Found
**Solution:**
- For Android 12+: Settings → Special App Access → Install Unknown Apps
- Select your browser/file manager
- Enable permission

### Issue: APK File Corrupted
**Solution:**
- Delete partially downloaded file
- Re-download from direct link
- Verify file size: ~14.5 MB
- Check 100% download completion

### Issue: Permission Denied During Installation
**Solution:**
- Check parental controls
- Ensure you're device owner
- Disable security apps temporarily
- Try installing via USB transfer
